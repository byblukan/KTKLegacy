Где взять Qt SDK 1.2.1 для сборки KTKLegacy под Symbian (Windows)
===================================================================

Официально Qt SDK 1.2.1 больше не раздаётся: сайт Nokia закрыт, на qt.io его нет.
Копии сохранились на Internet Archive. Ссылки найдены поиском 07.11.2026 и заранее
не проверялись, поэтому контрольную сумму сверяйте обязательно.


1. Установщик
-------------

Internet Archive, «Nokia and Symbian SDKs and Dev tools - Part 2»:
    https://archive.org/details/nokia_sdks_n_dev_tools2

Файл: QtSdk-offline-win-x86-v1.2.1.exe (около 1,7 ГБ), полный офлайн-установщик.

Проверка MD5 после скачивания (сумма из стороннего блога, официальной нет):
    ef3c33cb8c5aa3104a83cec592da8cc1

В PowerShell:
    Get-FileHash QtSdk-offline-win-x86-v1.2.1.exe -Algorithm MD5


2. Цель для Symbian (SymbianSR1Qt474)
-------------------------------------

build-symbian.cmd ищет папку:
    C:\QtSDK\Symbian\SDKs\SymbianSR1Qt474

По сообщениям пользователей, в офлайн-установщике может не быть Belle SDK.
Если после установки этой папки нет, она есть отдельным архивом в Part 1:
    https://archive.org/details/nokia_sdks_n_dev_tools
    Файл: Belle_SDK_for_QtSDK_v1.2.1_SymbianSR1Qt474.7z
Распакуйте его в C:\QtSDK\Symbian\SDKs\


3. Советы по установке
----------------------

- Ставьте в C:\QtSDK (путь по умолчанию). Если SDK стоит в другом месте, перед
  сборкой выполните:  set QTSDK=D:\путь\к\QtSDK
- Проект кладите на тот же диск, что и SDK, в путь без пробелов и кириллицы,
  например C:\work\ktk-symbian. Так требует сборочная система Symbian.
- Если установщик зависает на 1%: сначала поставьте Qt SDK 1.2, а поверх него 1.2.1
  (совет с форума Qt).
- Сборка: запустите build-symbian.cmd из папки проекта. Получится KTKLegacy_<версия>.sis.
  Подробности в README.md.
- На телефоне включите: Настройки -> Приложения -> Установки -> Параметры установки ->
  Установка ПО: Все.
